# Парсер каталога книг в Excel

Скрипт на Python собирает данные с каталога и сохраняет их в аккуратную таблицу Excel или CSV: название, цена, рейтинг, наличие и ссылка на товар. Работает на учебном сайте [books.toscrape.com](https://books.toscrape.com), который создан специально для практики парсинга. Тот же подход подходит для мониторинга цен конкурентов, сбора каталога товаров и выгрузки данных для анализа.

## Возможности

- Сбор нужного числа страниц каталога (`--pages`)
- Фильтры по минимальному рейтингу и максимальной цене
- Выгрузка в Excel (`.xlsx`: жирная шапка, закреплённая строка, фильтры, ширина столбцов) или в CSV
- Паузы между запросами, повторные попытки при сбоях сети, понятные сообщения об ошибках
- Битые карточки товаров пропускаются, а не ломают весь запуск

## Запуск

```
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
python scraper.py
```

Примеры:

```
python scraper.py --pages 10 --output books.xlsx
python scraper.py --pages 5 --min-rating 4 --max-price 30 --output cheap_good.csv
```

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `--pages` | сколько страниц каталога собрать | 5 |
| `--output` | файл результата (`.xlsx` или `.csv`) | `books.xlsx` |
| `--min-rating` | минимальный рейтинг от 0 до 5 | 0 |
| `--max-price` | максимальная цена в £ | без ограничения |
| `--delay` | пауза между запросами, секунд | 0.5 |

## Технологии

Python 3.10+, requests, BeautifulSoup4, openpyxl
